## Top insights across all 10 experts

1. **Listen before posting** — F5Bot/social listening on brand, category, competitor keywords
2. **Warm up accounts** — 30–90 days; karma + age before any promotion
3. **9:1 or 90/10 rule** — Overwhelmingly helpful vs promotional
4. **Reddit → Google → AI** — Threads rank in SERPs; LLMs cite Reddit for buyer queries
5. **Start in external subreddits** — Branded communities only when resourced (Krista, Olena)
6. **Measure beyond last-click** — Brand search lift, AI citations, assisted conversions
